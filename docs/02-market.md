# Исследование рынка

Проведено 2026-08-06 (веб-ресёрч). Цифры и ссылки — на дату исследования.

## 1. Спрос в Казахстане

- **~90 000 казахстанцев** учатся за рубежом (UNESCO) — **9-е место в мире** по outbound-студентам; ~80% учатся за свой счёт.
- Направления: Россия доминирует (~60–70 тыс., но доля падает после 2022), далее Турция, Кыргызстан, Чехия, США.
- **США:** всего ~2 000 казахстанских студентов, и лишь ~10% потенциальных абитуриентов вообще рассматривают США — маленькая база, огромный потенциал роста, высокая готовность платить.
- **Южная Корея:** 1 000+ казахстанцев только за первое полугодие 2024 — самое быстрорастущее направление, и хуже всего покрытое существующими платформами.
- Академическая мобильность (2023): 4 400 студентов, +22,5% за год (Польша, Турция, Германия, Франция, Литва).
- **Болашак:** ~950 стипендиатов (в основном магистратура: США 488, UK 256) — престижный якорь, но не ядро аудитории бакалавриата.
- Воронка растёт: ~160 000 выпускников школ в год, прогноз 200–250 тыс. в течение пяти лет.

**Ключевой аргумент:** только 10% потока рассматривают США → выбор направления сегодня определяется **доступом к информации**, а не предпочтениями. Это и есть арбитраж, который закрывает продукт.

## 2. Конкуренты

### Прямые (и почему они не решают проблему)

| Платформа | Что есть | Почему не работает для казахстанца |
|---|---|---|
| **UniPage** (лидер СНГ) | каталог + платное агентство | Бесплатный каталог — приманка к консультанту (полное сопровождение ~100 000 ₽, поиск программы 63 000 ₽). Нет фильтра по своим баллам, нет дедлайнов, данные устаревшие, рублёвые цены |
| **Studyportals** (Bachelorsportal и др.) | 270k+ программ, 110 стран, бесплатно | Только англоязычные программы (мимо Турции/Кореи/Китая), только английский интерфейс, слабые данные по требованиям («пройдёт ли мой SAT» — нет ответа), пустые поля стоимости, ноль КЗ-контекста |
| **Niche.com** | отличный UX, отзывы | Только США и только для американцев: in-state tuition, нет IELTS-минимумов, виз, международных сборов |
| **Common App** | подача в 1000+ колледжей США | Это рельсы подачи, не дискавери. Их бесплатный Requirements Grid (PDF) полезен как источник данных |
| **EducationUSA Kazakhstan** | бесплатные консультации (госпрограмма США) | Только США, ограничены пропускной способностью живых консультантов, нет продукта/базы. Скорее партнёр, чем конкурент |

### Казахстанские агентства = доказательство спроса

Nova Education (от 108 000 ₸), Impact Admissions (от 20 000 ₸), SmarTestPrep (сопровождение от $1 200), Dreamway to Korea (от $500), полные пакеты у ряда агентств — **650 000–1 000 000 ₸**. Также: GET Education, Excourse, UniStudy, New Generation, Crimson Education.

Их бизнес-модель — информационная асимметрия: ни одно не публикует открытую базу. Люди платят $250–$2 300 за информационное посредничество → спрос на структурированную информацию доказан деньгами.

### Вывод: свободная ниша

Никто не предлагает **бесплатный + структурированный + русско/казахоязычный + мульти-страновой** каталог с фильтрацией по своим баллам, трекингом дедлайнов и избранным. Это дыра, в которую заходим.

## 3. Источники данных

| Источник | Покрытие | Ключевые поля | Лицензия |
|---|---|---|---|
| **College Scorecard API** | ~6 000+ вузов США | ~139 полей: tuition, SAT p25/p75, admission rate | Бесплатно, public domain. Ключ бесплатный (DEMO_KEY: 1000 req/час) |
| **IPEDS / NCES** | 7 000+ вузов США | tuition, admissions, SAT/ACT, enrollment | Бесплатно, bulk CSV, public domain |
| **HESA / Discover Uni** | все вузы UK | курсы, результаты выпускников | **CC BY 4.0** — коммерческое использование ОК с атрибуцией |
| **Hipolabs API** | ~9 700 вузов мира | только имя, страна, домен | Бесплатно, без ключа. Годится как глобальный справочник имён |
| **UCAS Courses Data** | курсы UK | листинги | Платная коммерческая лицензия — не используем |
| **QS / THE рейтинги** | мировые рейтинги | ранги | **CC BY-NC-ND / платно для коммерции** → храним только номер + ссылку наружу, таблицы не воспроизводим |
| **Common App Req Grid** | ~1 100 колледжей | тест-политика, англ. требования | Бесплатный PDF, не API; перед машинным использованием проверить ToS |

### Главная правда о данных

Поля, которые реально экономят время пользователю — **дедлайны, IELTS-минимумы, сборы за подачу для иностранцев, прямые ссылки на порталы** — не существуют ни в одном бесплатном структурированном источнике. Ни в одном. Их можно получить только ручной курацией по официальным сайтам (или парсингом с юридической осторожностью — фаза 2+).

Следствия:
1. v1 = **100–300 вручную проверенных вузов**, а не «весь мир из API» (иначе получим те же пустые поля, что у Studyportals);
2. курация — основная трудозатрата (~20–30 мин/вуз) и одновременно **moat**: конкуренту придётся повторить те же сотни часов работы;
3. свежесть данных обязана быть видимой фичей продукта (`last_verified_at` в UI).

## 4. Выводы для продукта

- Стартовое покрытие по казахстанскому спросу: США ~40 вузов / UK ~15 / ЕС ~10 / Корея+Япония+Китай+Гонконг ~20 / Турция ~15.
- Корея и Турция — недообслуженные растущие направления, там проще всего стать «единственным источником».
- Против инкумбентов играем «бесплатно + прозрачно + на русском»: их бизнес-модель не позволяет это скопировать без каннибализации выручки.
