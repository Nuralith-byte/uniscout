# Бизнес: аналитика и монетизация

## Аналитика с первого дня

Инструменты: PostHog Cloud free (1 млн событий/мес) или Umami (без cookie-баннера) **плюс** собственная таблица `outbound_clicks` в Postgres — данные, на которых будет строиться прайсинг, храним у себя, а не арендуем у аналитики.

### События

| Событие | Зачем |
|---|---|
| `search_performed` (+ фильтры) | какие страны/бюджеты/баллы реально ищут → приоритеты курации |
| `university_viewed` | конверсия выдача → карточка: релевантна ли выдача |
| `favorite_added` | глубина интента; 3+ избранных = когорта удержания |
| **`apply_url_clicked`** | **момент ценности продукта** и будущая база прайсинга спонсорских профилей |
| signup на гейте избранного | готовность коммититься |
| Возвраты за 30 дней | поступление — процесс на месяцы; удержание = главный KPI |
| Карточки с нулём просмотров | мёртвый вес курации — депризоритизировать |

### Гипотезы для проверки данными

1. Корея/Турция недообслужены относительно спроса (ставка: их будут искать больше, чем предполагает англоязычный контент-рынок).
2. Реальные диапазоны SAT/IELTS пользователей покажут, какие вузы курировать следующими (вероятно, mid-tier, а не Лига плюща).
3. Сезонность: пик октябрь–январь (дедлайны США), отдельные волны под Корею/Турцию.

## Монетизация — последовательность, не MVP

Принцип: сначала бесплатный каталог и трафик, монетизация — поверх доверия, и никогда — против интересов абитуриента.

### Шаг 1: лид-ген для test-prep (самый быстрый первый доход)
IELTS/SAT-центры Алматы и Астаны (SmarTestPrep и десятки других) — живые локальные рекламодатели с бюджетами. Пользователь с SAT 1100, мечтающий о вузе с p25=1400 — идеальный лид для курсов. **Нет конфликта интересов:** курс реально помогает абитуриенту.

### Шаг 2: freemium-инструменты
Бесплатно навсегда: каталог, фильтры, избранное. Платно (~15–30 тыс. ₸/год): напоминания о дедлайнах, трекер заявок, ревью эссе.
Ценовой якорь: агентства берут 108 тыс. – 1 млн ₸ — премиум за 15–30 тыс. выглядит подарком.

### Шаг 3: спонсорские профили вузов (модель Niche, ~$10k/год с вуза)
Когда появится устойчивый трафик из Центральной Азии. Аргумент для международных офисов: ЦА — регион, до которого им объективно трудно дотянуться, а тут — концентрированная целевая аудитория с измеримыми кликами (`outbound_clicks` = доказательство). Спонсорство = выделение в выдаче + расширенный профиль, **не** искажение данных о требованиях.

### Шаг 4 (осторожно): комиссия за зачисление
Индустрийный стандарт 10–20% первого года обучения. Самый большой чек, но превращает платформу в агентство со всеми конфликтами интересов. Только если/когда — и с обязательной пометкой партнёрских вузов.

### Побочное: партнёрки
Переводы денег (Wise/Flywire), студенческие страховки, жильё — конвертируются на этой аудитории неплохо, добавляются безболезненно.

## Почему это работает именно в Казахстане

1. **Спрос доказан деньгами:** ~90 тыс. студентов за рубежом, агентства процветают на информационном посредничестве.
2. **Информационная асимметрия — уязвимость инкумбентов:** их бизнес требует держать данные закрытыми; наш бесплатный прозрачный каталог структурно некопируем для них без каннибализации выручки.
3. **Дистрибуция бесплатна:** студенческие Telegram/Instagram-сообщества, школьные консультанты, Bolashak-окружение.
4. **Окно возможности:** поток из России перенаправляется, Корея/Турция растут, а обслуживающих их платформ на русском нет.
