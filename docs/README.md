## TL;DR

Бесплатный русскоязычный каталог зарубежных вузов с фильтрацией «мой SAT + мой IELTS + мой бюджет», дедлайнами, избранным и прямыми ссылками на порталы подачи. Ниша свободна: аналогов нет, а казахстанские агентства берут 108 тыс. – 1 млн ₸ за ту же информацию. Данные (ручная курация ~100–300 вузов) — это и есть продукт и конкурентное преимущество.
