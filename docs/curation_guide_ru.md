# Гайд по курации данных

Данные — это продукт. Один вуз занимает 20–30 минут. Норма: 20 вузов в неделю, фиксированными батчами (не «пока не устану»).

## Процесс

1. Открой официальную страницу **international admissions** университета (не агрегатор!).
2. Заполни строку в Google Sheet (одна строка = один вуз, бакалавриат).
3. Обязательно заполни `source_url` (страница, откуда взял данные) и `last_verified_at` (сегодняшняя дата).
4. Поставь `is_published=TRUE` только когда проверены все ключевые поля.
5. Запусти импорт: `python -m app.ingest.import_sheet` — невалидные строки будут отклонены с объяснением.

## Колонки Sheet

| Колонка | Что писать | Пример |
|---|---|---|
| slug | латиницей, дефисы | `university-of-toronto` |
| name_en / name_ru | официальное название | `University of Toronto` / `Университет Торонто` |
| aliases | русские написания через `\|` | `Торонто\|UofT` |
| country_code | ISO-код | `CA` |
| city | город | `Toronto` |
| website_url | главный сайт | `https://www.utoronto.ca` |
| **apply_url** | **прямая ссылка на портал подачи — самое ценное поле** | `https://future.utoronto.ca/apply` |
| application_system | `common_app` / `ucas` / `direct` | `direct` |
| sat_required | `required` / `optional` / `not_used` | `not_used` |
| sat_min, sat_p25, sat_p75 | если публикуют | `1300`, `1400`, `1550` |
| ielts_min / toefl_ibt_min | минимум для admission (не для стипендии) | `6.5` / `89` |
| notes_ru | важные нюансы 1-2 предложениями | «Нужен Foundation-год» |
| tuition_amount + tuition_currency | за год, **в оригинальной валюте** | `61720` + `CAD` |
| application_fee_amount + _currency | сбор за подачу | `180` + `CAD` |
| deadline_regular | основной дедлайн, ГГГГ-ММ-ДД | `2027-01-15` |
| intake_term | на какой набор | `Fall 2027` |
| source_url | откуда данные | ссылка на admissions-страницу |
| last_verified_at | дата проверки, ГГГГ-ММ-ДД | `2026-08-06` |
| curated_by | кто проверил | `nurdaulet` |
| is_published | TRUE только после полной проверки | `TRUE` |

## Правила

- **Никогда не копируй описания текстом с чужих сайтов** — факты (цифры, даты) не защищены копирайтом, тексты защищены. `description_ru` пиши своими словами.
- Рейтинги QS/THE не переносить таблицами — только номер + ссылка на их сайт (лицензия).
- Валюту не конвертируй — пиши как на сайте вуза, `amount_usd` посчитается автоматически.
- Если поле неизвестно — оставь пустым. Пустое поле честнее выдуманного: в UI появится «уточняйте на сайте».
- Раз в квартал (и обязательно в мае–июле, перед сезоном подачи) — спринт перепроверки: `python -m app.ingest.freshness_report` покажет строки старше 120 дней (скрипт — TODO фазы 2).
